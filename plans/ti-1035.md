Step 4 of ti-1031.

- MCP: a `ticketRef` argument type unmarshals from a JSON string or an
  integer (integer = legacy number) and resolves through `tix.ResolveRef`.
  Tools set `InputSchema` from `jsonschema.For` with a `TypeSchemas` entry
  giving `ticketRef` the type `["string", "integer"]`. The int-only
  `legacyRef` helpers go.
- e2e.sh: tickets are tracked by the UUID captured when they are added, and
  expected output is built from the ticket's current short ref (looked up
  through `tix show`), since short refs grow as more tickets land.
- README.md and mcp/README.md describe UUID ids, short refs, legacy
  numbers, and the string-or-integer MCP input.
