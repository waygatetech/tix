`Plan` gains `Extra map[string]any` (`json:"-" yaml:"-"`). `ParsePlan` drops
`KnownFields`; it decodes the frontmatter a second time into a map and keeps
keys not owned by tix as `Extra`. A `hookInput` helper merges `Extra` under the
plan's own JSON (tix fields win). `storePlan` is unchanged, so extensions are
never cached.

`runPlanHook` sends `hookInput(plan)` and sets `TIX_HOOK=plan`. `Approve(ctx,
id)` re-parses the plan file at the cached path for its extensions, runs
`approve-hook` (via `hookPath`) with `TIX_HOOK=approve` and `{ticket, plan}` on
stdin, and only stores the approval if it exits 0. Done hook is untouched
(argv id, documented as such). README gets a Hooks section with the contract.
