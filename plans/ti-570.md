`done.go`: `doneHookPath(project)` resolves the hook the same way `planHookPath` does (the two share one helper in plans.go). `RunDone(ctx, id)` runs the hook in the project's repo_path, with the ticket ID as its argument. It captures stdout and caps it at 64 KiB. Valid JSON is stored as JSON and anything else as a string. On a non-zero exit, it records `done_attempt {result: fail, stage, output}` in its own insert, so the event survives the refusal, and returns an error that includes the output. On success, it records `done_attempt {result: pass}` inside Done's transaction. With no hook configured, it records pass and closes the ticket, same as today. `cmd/done.go` calls RunDone. The MCP server doesn't call Done, so it stays unchanged.
