ti-1031 becomes an epic. This plan sets the contracts and decisions for the whole change. Each child plan sets `epic: ti-1031` and stays within these contracts, so it lands at tier 0.

Children, each depending on the previous one:
1. **Schema migration** (`internal/tix/db.go`, tests): rebuild `tickets` with `id TEXT PRIMARY KEY`, `legacy_id INTEGER UNIQUE`, backfill UUIDs, and rewrite FK and reference columns in one migration transaction. `created_at` already exists, so list queries switch to `ORDER BY created_at, id`.
2. **Ref resolution** (`internal/tix/ids.go`, tests): `ShortIDs` computes the shortest unique prefix (min 4) across all ticket ids. `ResolveRef` matches `[key-]hex-prefix` or a legacy number, and errors on ambiguity with the matching list. The key-mismatch check stays.
3. **Internal switch** (`internal/tix`, `cmd`): `int` ticket ids become `string`, and display goes through `FormatID`.
4. **Contract switch** (`mcp`, JSON output, `e2e.sh`, READMEs, AGENTS guidance): string ids out, string-or-integer in.

Follow-up outside this repo: a tixbar ticket for string ids.
