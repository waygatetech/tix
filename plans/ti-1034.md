Step 3 of ti-1031.

- Append `uuidMigration` to `migrations`. `Add` inserts `uuid.NewString()`
  (google/uuid is already in go.sum).
- `Ticket.ID`, `ParentID`, dependency ids, lease/revert/event ticket ids, and
  every id parameter in `internal/tix` and `cmd` become `string`.
  `ResolveRef` becomes `resolveUUIDRef`; the old `ParseRef` goes.
- Display: `ShortIDMap()` reads every ticket id once and returns `ShortIDs`.
  `FormatID(prefix, id string, shorts map[string]string)` renders
  `<key>-<short>`, falling back to the full id when it is missing from shorts.
- A short id grows when a new ticket collides with it, so names written
  earlier go stale. `tix plan` resolves the plan's `ticket:` and `epic:`
  fields as refs and compares ids instead of strings. The worktree lookup
  and `DefaultPlanPath` take any existing `<key>-<hex>` entry whose hex is a
  prefix of the id before falling back to the current short form.
- The web dashboard's own API (`cmd/web.go`, `cmd/web.html`) takes string
  ids, since it reads them from the same `Ticket` JSON.
- MCP keeps its integer schemas until the next child. Each integer goes
  through `ResolveRef(strconv.Itoa(n))`, a legacy lookup. JSON output emits
  string ids now, since it serializes `Ticket` directly. The next child
  updates docs and e2e and accepts string input.
