Reopened: tix no longer finds worktrees, branches, and plan files named
with the ticket's legacy number. The original change (UUID string ids in
internal/tix and cmd) merged in f3f70c2; its plan is in that commit.

Branch and worktree names are the same `<key>-<id>`, and tix looks branches
up only through the worktree directory, so fixing the worktree lookup covers
both.

- `refMatchesID(name, prefix, id string, legacy int)` also matches
  `<prefix>-<legacy>` when the ticket has a legacy number.
- `legacyNumber(id)` reads `tickets.legacy_id` (0 when NULL).
- `ticketDir` and `DefaultPlanPath` pass it through. `Check` and `RunDone`
  look it up before calling `ticketDir`.
