# ti-94: copy-only fast lane, plans outside the branch

## Tiering
`IndexPlan` reads `<repo_path>/.tix/copy-paths` (same parser as check-exempt).
When the plan has at least one path and every path matches a copy glob, tix
sets `Plan.CopyOnly` (`json:"copy_only,omitempty"`, `yaml:"-"`, and listed in
planKeys so frontmatter cannot forge it). Tier policy stays in the hook:
`hooks/plan-hook` gains a branch after the epic case, tier 0 with reason
"copy-only paths" when `copy_only` and no new_concepts or decisions, even with
contracts_changed. Code paths never match a copy glob, so their tiers don't change.

## Plan file outside the branch
`DefaultPlanPath` keeps `<repo>/plans/<ref>.md` when it exists, else uses
`~/.tix/plans/<project>/<ref>.md` (the location cerebro already uses via
--file). `tix check` already exempts only the plan's own path and diffs the
worktree, and the done hook passes vet the absolute path, so an external plan
needs nothing in the branch. A check test locks that in.

## Docs
README hooks section and `tix plan --help` describe `.tix/copy-paths`,
`copy_only`, and the external plan location.
